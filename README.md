# 📍 PEVsJoinville

Sistema de consulta de **Pontos de Entrega Voluntária (PEVs)** e **Rotas de Coleta Seletiva** em Joinville/SC.

## 🏢 Desenvolvido por
**Ambiental Limpeza Urbana e Saneamento Ltda**  
🌐 [ambiental.sc](https://ambiental.sc/)

## ⚡ Funcionalidades

### 🗺️ Mapa Interativo
- Visualização geoespacial com OpenStreetMap
- Zoom, pan e controles de navegação
- Geocodificação com Google Maps API

### 📍 Pontos de Entrega Voluntária
- **🟦 Caçamba**: Ponto de Entrega Voluntária
- **🟠 Contentor 1000L**: Ponto de coleta grande  
- **🟢 Contentor 120L**: Ponto de coleta pequeno

### 🚛 Rotas de Coleta Seletiva
- **🟡 Baú**: Rotas com veículos tipo baú
- **🔵 Compactador**: Rotas com veículos compactadores
- Informações de frequência, turno e horário

### 🔍 Sistema de Filtros
- Filtros por tipo de PEV
- Filtros por tipo de veículo
- Interface intuitiva com cores

### 🎯 Busca Inteligente
- Busca por endereços
- Marcador arrastável
- Integração Street View

## 🚀 Como usar

1. Abra o arquivo `index.html` em um navegador
2. Use a barra de pesquisa para encontrar um endereço
3. Aplique filtros para visualizar tipos específicos
4. Clique nos pontos para ver informações detalhadas
5. Arraste o marcador para explorar o Street View

## 📊 Dados

- **3.077 pontos** de PEVs mapeados
- **95.119 features** de rotas de coleta
- Dados em formato GeoJSON
- Coordenadas em CRS84 (WGS84)

## 🛠️ Tecnologias

- **Frontend**: HTML5, CSS3, JavaScript
- **Mapas**: Leaflet.js + OpenStreetMap  
- **APIs**: Google Maps (Geocoding + Street View)
- **UI**: FontAwesome, noUiSlider
- **Dados**: GeoJSON

## 📱 Responsividade

O sistema está otimizado para desktop. Para melhor experiência mobile, recomenda-se:
- Ativar CSS responsivo (comentado no código)
- Otimizar controles touch
- Ajustar tamanhos de popup
